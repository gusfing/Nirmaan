# NIRMAAN® | Luxury Interior Design Studio

A high-performance luxury interior architecture and spatial design studio web application built with modern web standards, smooth GSAP-powered motion choreography, interactive 3D elements, and responsive layouts.

## ✨ Features

- **Architectural Aesthetic**: Clean luxury typography, dynamic ambient lighting, and bespoke spatial showcases.
- **Interactive Spatial Portfolios**: Immersive project showcase with high-resolution imagery and material exploration.
- **Cost Estimator & Consultation Flow**: Integrated consultation modal and interactive architectural project planning calculators.
- **Fluid Animation System**: Smooth scrolling powered by Lenis and choreographed transitions.
- **Fast Production Builds**: Optimized with Vite.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/gusfing/Nirmaan.git

# Navigate into project directory
cd Nirmaan

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Build optimized static distribution
npm run build

# Preview production build locally
npm run preview
```
